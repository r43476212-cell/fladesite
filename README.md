# FLADE — сайт магазина обуви

Проект содержит исходную главную страницу, динамический каталог, Worker API, локальную D1-базу и админ-панель. Подробная инструкция локального запуска находится в `README_ADMIN.md`.

Каталог обновлён: скрипт изолирован внутри собственной функции и использует уникальные имена переменных, чтобы избежать конфликта `Identifier 'toggle' has already been declared`. Обновлены обе копии страницы: `catalog.html` и `public/catalog.html`.

Важно: текущий архив предназначен для локальной разработки и проверки. Он не был опубликован и не меняет работающий сайт. Не запускай `wrangler deploy`, пока мы не закончим локальные тесты и не проверим настройки.
