# FLADE — сайт, каталог и панель управления

## Состав
- `public/index.html` — главная магазина; визуальный дизайн сохранён.
- `public/catalog.html` — каталог, загружающий товары через API.
- `public/admin/` — панель управления товарами и пользователями.
- `public/setup-owner.html` — одноразовая форма первоначального создания владельца.
- `worker.js` — API, вход, сессии, управление товарами и изображения.
- `schema.sql` — схема D1.

## Важные настройки Cloudflare
Worker должен иметь привязку D1 с именем `DB`, которая указывает на существующую базу `local-flade-store-db`. В Worker Secrets должны быть заданы `SESSION_SECRET` и (только на время создания первого владельца) `BOOTSTRAP_SECRET`. Секреты не хранятся в этом архиве.

После успешного создания первого владельца удали `BOOTSTRAP_SECRET` в настройках Worker. Это закрывает маршрут первоначальной настройки; таблица `users` также не позволит создать второго владельца через этот маршрут.

Открытие страницы: `/setup-owner.html`. Админ-панель: `/admin/`. Проверка API: `/api/health`.

## Хранилище изображений
В этой версии изображения сохраняются в таблице `product_images` базы D1; R2 не используется. Максимальный размер одного загружаемого изображения — 400 КБ.

## Безопасность
Архив намеренно не включает `.dev.vars`, `key.txt`, `seed-owner.sql`, локальное состояние Wrangler или `node_modules`. Не помещай секреты в публичный репозиторий и не присылай их в чат.

## Ограничения проверки
Перед публикацией необходимо проверить привязку D1 и секреты в Cloudflare, потому что они относятся к аккаунту и не могут быть подтверждены только из локального архива. Нельзя гарантировать отсутствие всех ошибок без проверки в целевой среде.
